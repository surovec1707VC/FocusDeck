# FocusDeck

Локальная панель продуктивности для Windows 10/11: виджеты и макеты, заметки и задачи, Clipboard Hub, автоматизации, органайзер рабочего стола, интеграция с Windows, инструменты разработчика и коннекторы к программам и сервисам.

**Без ИИ, телеметрии, аналитики и облачной синхронизации.** Все данные хранятся в локальной SQLite. В сеть FocusDeck обращается только по вашему разрешению: погода, API Tester, облачные интеграции, обновления.

Стек: Tauri 2 · Rust (tokio, sqlx/SQLite) · React 19 · TypeScript · Tailwind CSS 4.

## Быстрый старт
**Требования:**
- Windows 10/11 и WebView2 Runtime (в Windows 11 уже установлен);
- Node.js 20+;
- Rust stable (MSVC) и Visual Studio Build Tools с «Разработка классических приложений на C++».

```bash
npm install
```
```bash
npm run tauri dev
```
Первая сборка Rust занимает несколько минут. Кэш сборки (`src-tauri/target`) со временем растёт до десятков гигабайт; `target\debug\incremental` можно удалять.

## Тесты
| Набор | Команда | Что покрывает |
|---|---|---|
| Rust: unit + integration | `npm run test:rust` | 123 теста: модули, разрешения, Safe Mode, автоматизации, органайзер, Clipboard Hub, интеграции, экспорт и импорт, восстановление, обновления; IPC-команды через mock-приложение Tauri (`ipc_tests.rs`); тесты безопасности (пути, инъекции, защищённые папки, враждебные файлы) |
| Типы фронтенда | `npm run typecheck` | TypeScript strict |
| UI smoke | `npm run test:smoke` | на запущенном приложении: все страницы, поиск, справка, IPC; только чтение |

Для smoke-теста приложение запускается с портом отладки WebView2:
```bash
powershell -Command "$env:WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS='--remote-debugging-port=9223 --remote-allow-origins=*'; npm run tauri dev"
```
Затем во втором терминале:
```bash
npm run test:smoke
```

## Реализованные функции
- **Оболочка:**
  - окно без рамки, трей, автозапуск (свёрнутым), запоминание позиции;
  - глобальные хоткеи;
  - тёмная, светлая и системная темы;
  - адаптивное меню;
  - быстрый поиск `Ctrl+K`, навигация с клавиатуры, знакомство при первом запуске;
  - встроенная документация, дизайн-система, доступность (роли ARIA, фокус, сокращение анимаций).
- **Центр управления и реестр модулей:**
  - 43 модуля: включение и выключение, настройки по схеме, статус, журнал, разрешения, сброс;
  - экспорт и импорт конфигурации.
- **Виджеты и макеты:** 14 видов виджетов; сетка с перетаскиванием и изменением размера (в том числе с клавиатуры); закрепление, сворачивание, скрытие; несколько макетов с хоткеями; индикатор активного макета и статуса модулей; меню быстрых действий.
- **Продуктивность:** заметки (Markdown, теги, проекты, корзина, экспорт), задачи (статусы, приоритеты, сроки, повтор, быстрое добавление строкой), сниппеты с переменными, помодоро, таймеры, секундомеры.
- **Clipboard Hub:** история (текст, HTML, RTF, изображения, файлы), пропуск приватных окон и менеджеров паролей, закрепление, лимиты, быстрые действия.
- **Automations:** 12 триггеров, 7 видов условий, 18 действий, шаблоны, тестовый запуск, подтверждения, журнал.
- **Desktop Organizer:** правила, предпросмотр, перемещение без удаления, отслеживание, откат.
- **Windows Integration:** окна, приложения, рабочие столы, звук, яркость, сеть, питание, скриншоты, буфер, уведомления, UI Automation; Permissions Center, Safe Mode, Action Log с отменой.
- **Developer Tools:** Git, Project Launcher, вкладки терминала, API Tester, Regex Tester, JSON/YAML.
- **Интеграции:** 13 коннекторов-манифестов, реестр, настройки, разрешения, секреты в Credential Manager, проверка состояния, журнал, Offline Mode.
- **Надёжность:**
  - обнаружение сбоя прошлого сеанса, `ErrorBoundary` на страницах;
  - резервная копия базы и её восстановление; экспорт и импорт данных в JSON;
  - корректное завершение: остановка фоновых задач, сброс WAL, закрытие базы.
- **Производительность:** ленивая загрузка страниц, кэш данных виджетов, опрос на паузе при скрытом окне, прореживание событий, лимиты истории, журналов и вывода; фоновые задачи на tokio.
- **Обновления:** проверка версии, список изменений, установка подписанного пакета с копией базы, откат данных; portable-режим.

## Известные ограничения
- **Платформа:** только Windows 10/11 x64. Нужен WebView2 Runtime.
- **Язык:** только русский интерфейс (строки вынесены в `src/i18n`).
- **Интеграции:** этап 1 — коннекторы не выполняют действий, OAuth-вход ещё не реализован; токены можно сохранить вручную.
- **Модуль «Файлы»** пока заглушка («в разработке»).
- **Подпись кода:** приложение и установщик не подписаны — SmartScreen предупреждает (см. [release.md](docs/release.md)).
- **Автообновления** работают только в сборках с ключом и адресом обновлений. Откат данных требует ручной установки прежней версии: миграции базы идут только вперёд.
- **Секреты API Tester:** переменные окружения хранятся в базе открытым текстом.
- **Команды:** быстрые действия и автоматизация «Выполнить команду» выполняются через `cmd` (с разрешением и подтверждением).
- **Portable-версия** не обновляется сама; секреты интеграций и в ней остаются в Credential Manager пользователя.
- **IPC-тесты** покрывают команды на `State`. Команды с диалогами и системными API проверяются unit-тестами и smoke-тестом.
- **Лицензия** самого приложения пока не выбрана.

## Чек-лист перед релизом
- [ ] Версия поднята в `package.json`, `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json`; запись в `CHANGELOG.md`.
- [ ] `npm run typecheck` и `npm run test:rust` — зелёные.
- [ ] `npm run test:smoke` на свежем профиле: все модули включены, затем выключены.
- [ ] Ручная проверка:
  - первый запуск (знакомство);
  - трей, автозапуск, `Ctrl+Alt+D`;
  - резервная копия и восстановление;
  - экспорт и импорт данных на чистом профиле;
  - сбой (завершение процесса) → баннер.
- [ ] Проверка безопасности:
  - все рискованные разрешения выключены на свежем профиле;
  - Safe Mode блокирует изменения;
  - Offline Mode блокирует облачные интеграции.
- [ ] Обе темы и узкое окно (760 px) без поломок.
- [ ] `npm run release:nsis`: установка, запуск, удаление (данные пользователя остаются).
- [ ] `npm run release:portable`: запуск с флешки, данные в `data\`.
- [ ] Подпись Authenticode для exe и установщика, проверка `Get-AuthenticodeSignature`.
- [ ] Обновления:
  - собрано с `TAURI_SIGNING_PRIVATE_KEY`, `FOCUSDECK_UPDATER_PUBKEY`, `FOCUSDECK_UPDATE_ENDPOINT`;
  - опубликованы `latest.json` и `.sig`;
  - проверено обновление с предыдущей версии и откат.
- [ ] SHA-256 артефактов опубликованы рядом с релизом.
- [ ] Выбрана и добавлена лицензия (`LICENSE`), обновлён текст в «О программе».
