# Дизайн-система

Единые правила интерфейса FocusDeck. Живые примеры всех компонентов в обеих темах — на странице **«О программе» → «Дизайн-система»** (`#/design`).

- Токены и утилиты: [`src/index.css`](../src/index.css).
- Компоненты: [`src/components/ui.tsx`](../src/components/ui.tsx), `Modal.tsx`, `ConfirmDialog.tsx`, `SettingsForm.tsx`.
- Тексты: `src/i18n/ru.ts`. В JSX — только строки из `t.*`, кроме страниц-примеров.

## Принципы
1. **Спокойно и плотно.** Это рабочий инструмент, а не лендинг. Основной текст 14 px, акцентный цвет только у интерактивного и активного.
2. **Две темы равноправны.** Каждый цвет пишется парой `x dark:y`. Тёмная тема — по умолчанию.
3. **Безопасность видна.** Всё, что меняет систему, подтверждается диалогом с красной кнопкой; кнопка «Отмена» в фокусе по умолчанию.
4. **Клавиатура — первый класс.** Всё достижимо с Tab, у всего есть видимый фокус, у иконок есть подписи.
5. **Ни одного тупика.** Пустой экран объясняет, что делать дальше. Ошибка говорит, что случилось, и даёт «Повторить».

## Цвета
| Роль | Токены | Где |
|---|---|---|
| Акцент | `accent-50…700` (oklch, hue 265) | основные кнопки, активный пункт меню, ссылки, фокус, выбранные вкладки |
| Нейтральные | `zinc-50…950` | фон, карточки, рамки, текст |
| Успех | `emerald-500/600` | «работает», сохранено |
| Внимание | `amber-500/600` | нет разрешения, не настроено, нужна перезагрузка |
| Опасность | `red-500/600` | ошибки, удаление, необратимые действия |
| Инфо | `sky-500` | нейтральные подсказки |

Поверхности:
- окно — `zinc-100/95` или `zinc-950/92`, с прозрачностью под Mica;
- карточка — `white/80` или `zinc-900/70`;
- поле ввода — `white` или `zinc-950`.

Рамки — `zinc-200` или `zinc-800`. Вторичный текст — `zinc-500`.

Статусные фоны — цвет с прозрачностью 10–15 % и текст того же оттенка, например `bg-emerald-500/15 text-emerald-700 dark:text-emerald-400`. Готовые варианты собраны в `Badge`.

## Типографика
Шрифт — Segoe UI Variable (системный), моноширинный — Cascadia Code.

| Уровень | Класс | Применение |
|---|---|---|
| Заголовок страницы | `text-2xl font-semibold tracking-tight` | `PageHeader` |
| Заголовок карточки | `text-lg font-semibold` / `font-semibold` | секции |
| Заголовок диалога | `text-base font-semibold` | `Modal`, `ConfirmDialog` |
| Основной | `text-sm` (по умолчанию у `body`) | всё остальное |
| Подписи и подсказки | `text-xs text-zinc-500` | hint, метаданные, `label` |
| Код и сочетания | `font-mono text-xs`, `kbd` | пути, команды, хоткеи |

Текст интерфейса не выделяется мышью (`select-none` у body). То, что полезно копировать — пути, сообщения ошибок, вывод, — помечается `select-text`.

## Отступы и формы
- Шаг сетки — 4 px (единицы Tailwind).
- Карточка: `p-4`, между карточками `gap-4`. Страница: `p-4 sm:p-6`, ширина до `max-w-6xl`.
- Радиусы: `rounded-md` 6 — пункты меню, `rounded-lg` 8 — поля и кнопки, `rounded-xl` 12 — карточки и окна.
- Тени: `shadow-sm` у карточек; `shadow-xl` или `shadow-2xl` у всплывающих меню и окон.

## Компоненты

### Кнопки (`index.css`)
| Класс | Когда |
|---|---|
| `btn-primary` | одно главное действие на экране или в окне |
| `btn-secondary` | обычные действия |
| `btn-ghost` | третичные: «Отмена» в шапке, ссылки-кнопки |
| `btn-danger` | удаление в списках (красный текст); в диалоге подтверждения — сплошная красная |
| `btn-sm` | модификатор: компактные кнопки в баннерах и меню |
| `icon-btn` / `<IconButton label>` | кнопка-иконка 32×32; всегда с `aria-label` и `Tooltip` |

Иконка в кнопке — 16 px (`size-4`) слева от текста. Недоступная кнопка — `disabled`, её не прячут, если причина понятна.

### Поля
- `input` — одинаков для `input`, `select` и `textarea`.
- Подпись — `<Field label>` или класс `label`; подсказка под полем — `text-xs text-zinc-500` и `aria-describedby`.
- Ошибку валидации присылает backend; она показывается в `ErrorBanner` над формой.
- Сочетания клавиш вводятся через `HotkeyInput` (запись нажатия), а не текстом.

### Toggle
`<Toggle checked onChange label>` — `role="switch"`. Используется для «вкл/выкл» с немедленным эффектом. Если изменение нужно сохранить кнопкой, это тоже Toggle, но внутри формы с «Сохранить».

### Карточки и строки
- `card` — основной контейнер.
- `<Row title hint>` — строка настройки «текст слева, контрол справа». Строки разделяются `divide-y`.

### Метки
`<Badge tone="neutral|accent|ok|warn|error">` — статус, категория, риск. Текст метки — строчными: «работает», «не настроена».

### Вкладки
`<Tabs tabs value onChange label>` — `role="tablist"`, переключение стрелками ← → и клавишами Home/End (roving tabindex). Для вкладок-страниц (Developer Tools) используется `NavLink` с той же стилистикой.

### Модальные окна
- `<Modal open title onClose footer size>` — на `<dialog>`: ловушка фокуса, Esc, клик по фону и крестик закрывают окно.
- `<ConfirmDialog danger>` — подтверждение; по умолчанию в фокусе «Отмена».
- `useGuarded()` — если backend ответил `confirmation_required`, показывает его текст и повторяет вызов с `confirm: true`. Новые опасные действия подключаются только так.

### Таблицы
- Класс `data-table` на `<table>`: заголовки капителью `text-xs`, строки с разделителем и подсветкой при наведении.
- На узком окне таблица оборачивается в `overflow-x-auto`.

### Подсказки
- `<Tooltip text side>` появляется при наведении и при фокусе с клавиатуры, с задержкой 300 мс.
- Не заменяет подпись: у кнопки-иконки всё равно есть `aria-label`.
- Пункты бокового меню в узком режиме подписаны через `title`, вместе с сочетанием Ctrl+N.

### Состояния
| Состояние | Компонент |
|---|---|
| Загрузка | `<Spinner>` (с `role="status"`) |
| Пусто | `<EmptyState icon title hint action>`, простой вариант — `<Empty>` |
| Ошибка действия | `<ErrorBanner message onClose>` над содержимым |
| Ошибка загрузки | `<ErrorState message onRetry>` |
| Падение страницы | `ErrorBoundary` вокруг маршрутов: «Попробовать снова», «На главную», «Перезагрузить интерфейс» |
| Прошлый сеанс упал | `CrashNotice`: журналы, Safe Mode, «Понятно» |

### Иконки
- Набор — lucide-react: 16 px в тексте и кнопках, 18 px в меню, 20–24 px в шапках карточек.
- Брендовых логотипов нет: интеграции получают нейтральные иконки (GitHub → `GitBranch` и т. п.).
- Декоративные иконки помечаются `aria-hidden`.

## Оболочка и навигация
- **Боковое меню.** От ширины `lg` — иконки с подписями, уже — только иконки. Пункты модулей скрываются, когда модуль выключен. Сверху — кнопка поиска.
- **Быстрый поиск** (Ctrl+K). Ищет по страницам, макетам, быстрым действиям, командам приложения и модулям; «ё» равно «е». Выбор стрелками, Enter открывает.
- **Сочетания клавиш:**
  - Ctrl+1…9 — пункты меню;
  - Ctrl+, — Настройки;
  - F1 или ? — справка по сочетаниям;
  - Esc закрывает любое окно или меню.
- **Пропуск навигации.** Первый Tab показывает ссылку «Перейти к содержимому».
- **Знакомство.** Показывается при первом запуске (ключ `focusdeck.onboarding.v1` в localStorage): приватность, тема, основные модули, клавиатура. Его можно открыть снова из быстрого поиска и со страницы «О программе».

## Доступность
- У каждого интерактивного элемента есть доступное имя: текст, `aria-label` или `label`.
- Фокус всегда виден: `outline` 2 px акцентного цвета.
- Роли: `switch`, `tablist`/`tab`, `dialog`, `menu`/`menuitem`, `listbox`/`option` + `combobox` в поиске, `alert` у ошибок, `status` у уведомлений и загрузки.
- Контраст текста — не ниже 4.5:1. Вторичный `zinc-500` используется только для подсказок.
- Анимации не дольше 150 мс; при `prefers-reduced-motion` они отключаются.
- Виджеты на Обзоре двигаются с клавиатуры: стрелки на ручке перемещают виджет, Shift+стрелки меняют размер.
