# Руководство пользователя

FocusDeck — локальная панель продуктивности для Windows 10/11. Она работает без интернета, учётных записей и облака: все данные хранятся на этом компьютере.

## Первый запуск
- **Знакомство.** При первом запуске откроется знакомство из пяти шагов: приватность, тема, основные модули, клавиатура. Его можно пропустить и открыть снова (`Ctrl+K` → «Показать знакомство» или «О программе → Знакомство»).
- **Трей.** Значок FocusDeck живёт в трее. Крестик сворачивает окно в трей, выход — из меню значка.
- **Показ окна.** `Ctrl+Alt+D` показывает и скрывает окно из любой программы.

## Навигация
| Действие | Как |
|---|---|
| Быстрый поиск страниц, модулей, макетов и действий | `Ctrl+K` или «Поиск» в меню |
| Страницы меню по порядку | `Ctrl+1` … `Ctrl+9` |
| Настройки | `Ctrl+,` |
| Справка по сочетаниям | `F1` или `?` |
| Закрыть окно или меню | `Esc` |

Если окно узкое, меню показывает только иконки; подсказка появляется при наведении.

## Обзор и виджеты
- **Обзор** — сетка виджетов активного макета.
  - Перетаскивайте виджет за ручку `⋮⋮`, размер меняйте за правый нижний угол. С клавиатуры: фокус на ручке, затем стрелки (с Shift — размер).
  - У каждого виджета есть кнопки: настройки, закрепить, свернуть, скрыть, удалить.
  - **Быстрые действия** — меню ваших действий из Clipboard Hub.
  - Индикатор **«Модули: N из M»** показывает, каким модулям нужно внимание (например, не выдано разрешение).
- **Виджеты** — каталог: включение каждого вида, настройки и добавление на Обзор.
- **Макеты** — наборы виджетов («Работа», «Учёба», «Стрим» и т. п.).
  - У макета может быть своя глобальная горячая клавиша.
  - Макет можно скопировать вместе с виджетами.
  - Переключить макет: выбор на Обзоре, `Ctrl+K` или хоткей.

## Продуктивность
- **Заметки** — Markdown, теги, проекты, закрепление, корзина, экспорт в `.md` или `.txt`.
- **Задачи** — статусы, приоритеты, сроки, повторение, категории; быстрое добавление строкой («Купить молоко завтра !2 #дом»).
- **Сниппеты** — шаблоны с переменными `{{имя}}`: копировать или вставить в другую программу (нужно разрешение «Вставка»).
- **Таймеры** — помодоро, обратный отсчёт, несколько секундомеров. Работают и после перезапуска.

## Clipboard Hub
История буфера обмена: текст, ссылки, изображения, файлы.
- Включается вместе с разрешением «Чтение буфера обмена».
- Копирования из окон паролей и приватных окон браузеров не записываются.
- Закреплённые записи не удаляются автоматически. Лимит записей и срок хранения задаются в настройках модуля.

## Автоматизации
«Если → то»:
- **триггер:** время, интервал, запуск или остановка программы, активное окно, горячая клавиша, простой, сеть, питание и т. д.;
- **условия:** необязательны;
- **действия:** открыть, закрыть, уведомить, переключить макет, выполнить команду и т. д.

Порядок работы:
- **Тестовый запуск** показывает, что произошло бы, ничего не выполняя.
- Опасные действия (закрыть программу, команда, Корзина) выполняются только при выданном разрешении и после вашего подтверждения.
- У каждой автоматизации есть журнал запусков. Начать можно с шаблонов.

Подробно — [automations.md](automations.md).

## Desktop Organizer
Раскладывает файлы с рабочего стола по папкам по правилам (тип, расширение, маска имени, возраст, размер).
- Сначала всегда показывается предпросмотр.
- Файлы перемещаются, а не удаляются, и каждую операцию можно откатить.
- В системные папки (Windows, Program Files, корень диска) перемещать нельзя.

## Windows Integration и безопасность
Окна, приложения, рабочие столы, громкость, яркость, сеть, питание, скриншоты.
- **Разрешения.** Каждое действие требует своего разрешения. Страница «Разрешения» показывает, кто и когда им пользовался.
- **Safe Mode.** Выполняются только действия из белого списка, любое изменение подтверждается.
- **Action Log.** Журнал выполненных действий, многие из них можно отменить.

Подробно — [security.md](security.md).

## Developer Tools
Git (статус, diff, коммит, push и pull с подтверждением), список проектов с запуском, вкладки терминала, API Tester, Regex Tester, JSON/YAML. Каждый инструмент включается отдельно.

## Интеграции
13 коннекторов: GitHub, GitLab, VS Code, Windows Terminal, OBS, Twitch, Discord, Telegram, Notion, Google Calendar, Spotify, браузер, файлы.
- Токены хранятся в Windows Credential Manager.
- **Offline Mode** (включён по умолчанию) приостанавливает все облачные коннекторы.
- В этой версии коннекторы ещё не выполняют действий.

## Центр управления
- Все 43 модуля: поиск, категории, включение и выключение, настройки, статус, журнал, разрешения, сброс настроек.
- Выключенный модуль скрывает свои страницы и виджеты; данные сохраняются.
- Экспорт и импорт конфигурации модулей — здесь же.

## Резервные копии и перенос
«Настройки → Резервная копия»:
- **Создать копию** — полная копия базы в один файл `.sqlite`.
- **Восстановить** — выберите копию: она проверяется и применяется при следующем запуске. Текущая база не удаляется, а сохраняется рядом (`focusdeck.before-restore-…`).
- **Экспорт данных (JSON)** — выбранные разделы: настройки и модули, макеты, заметки, задачи, календарь, сниппеты, автоматизации. Подходит для переноса на другой компьютер.
- **Импорт** — записи с теми же идентификаторами заменяются, новые добавляются, остальное не меняется.

Секреты интеграций не попадают ни в копию, ни в экспорт.

## Если что-то пошло не так
- **Сбой прошлого сеанса.** После аварийного закрытия FocusDeck покажет баннер. Из него можно открыть журналы, включить Safe Mode или просто закрыть его.
- **Ошибка на странице.** Если страница не отобразилась, остальное приложение продолжает работать. Нажмите «Попробовать снова» или «Перезагрузить интерфейс».
- **Журналы:** «О программе → Журналы» (`%APPDATA%\com.focusdeck.app\logs` или `data\logs` в portable-версии).
- **Модуль ведёт себя странно:** «Центр управления → модуль → Статус» и «Журнал»; «Сбросить настройки» возвращает значения по умолчанию.

## Обновления
Модуль «Обновления» (выключен по умолчанию):
- проверка новой версии и список изменений;
- установка подписанного обновления: перед ней база копируется;
- откат данных к состоянию до обновления.

Проверка при запуске включается в настройках модуля. Установка всегда требует подтверждения.

## Portable-версия
Распакуйте архив в любую папку, например на флешку. Все данные хранятся в папке `data` рядом с `FocusDeck.exe`. Нужен WebView2 Runtime (в Windows 11 он уже есть).

## Встроенная документация
«О программе → Документация» (`Ctrl+K` → «Документация») — все эти разделы доступны прямо в приложении, без сети.
