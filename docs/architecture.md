# Архитектура FocusDeck

Локальное desktop-приложение для Windows 10/11 на Tauri 2. **Без ИИ, телеметрии, аналитики, облачной синхронизации и сбора данных**: все данные лежат в локальной SQLite. В сеть обращается только виджет «Погода» (open-meteo.com) и только с разрешением «Сеть: прогноз погоды». Облачные интеграции выключены и приостановлены Offline Mode (по умолчанию включён); на текущем этапе они не обращаются к внешним API.

### Окно и трей
- `decorations: false` + `transparent: true`: системной рамки нет, оболочка рисует свой заголовок со скруглёнными углами.
- Окно создаётся скрытым (`visible: false`) и показывается в `setup`, если не нужен запуск свёрнутым (настройка «Запускать свёрнутым» или флаг `--minimized` от автозапуска).
- Крестик → `CloseRequested` → при «Закрытие сворачивает в трей» окно прячется, иначе приложение завершается. Выход — из меню трея.
- Позиция, размер и «развернуто» сохраняются (`tauri-plugin-window-state`). Видимость и рамка из сохранённого состояния не восстанавливаются: ими управляет приложение.
- Повторный запуск exe не открывает вторую копию, а показывает окно (`single-instance`).

### Горячие клавиши
Регистрируются, только если включены одновременно: настройка «Глобальные горячие клавиши», модуль «Глобальные горячие клавиши» и разрешение `system.global_hotkeys`. Сочетания автоматизаций требуют ещё модуль «Автоматизации» и модуль самой автоматизации. По умолчанию `Ctrl+Alt+D` показывает или скрывает окно. Сочетание, занятое другой программой, не сохраняется: настройки откатываются с понятной ошибкой.

### Разрешения
| id | По умолчанию | Что даёт |
|---|---|---|
| `system.global_hotkeys` | выдано | глобальные хоткеи |
| `system.autostart` | нет | автозапуск с Windows |
| `app.notifications` | выдано | уведомления от автоматизаций (внутри окна) |
| `clipboard.read` | нет | Clipboard Hub: запись истории |
| `system.close_apps` | нет | закрытие программ автоматизациями (с подтверждением) |
| `files.delete` | нет | перемещение файлов в Корзину автоматизациями (с подтверждением) |
| `system.run_commands` | нет | команды терминала в быстрых действиях (каждый запуск подтверждается) |
| `network.weather` | нет | виджет «Погода» |
| `system.launch_apps` | нет | виджет «Запуск программ» |
| `system.paste` | нет | «Вставить» у сниппетов (Ctrl+V в другой программе) |

Включение функции в «Настройках» считается согласием и выдаёт разрешение (источник `settings`). Каждое изменение и каждый отказ пишется в `permission_logs`.

### Автоматизации
- 12 триггеров, 7 типов условий, 18 действий — см. [automations.md](automations.md).
- Опасные действия (закрытие программ, команды, удаление файлов в Корзину, запуск скриптов) выполняются только после подтверждения пользователем и при выданном разрешении.
- Если модуль «Автоматизации» или модуль-владелец выключен, запуск записывается как `skipped`. Журнал ограничен 500 записями на автоматизацию.

## База данных
Файл `%APPDATA%\com.focusdeck.app\focusdeck.sqlite`. Миграция `0001_init.sql` создаёт 15 таблиц; `0003_widget_system.sql` добавляет сетку виджетов, профили макетов, `widget_cache`, `calendar_events`, `notifications`. Исходно: settings, modules, module_settings, widget_layouts, widgets, automations, automation_logs, tasks, notes, snippets, clipboard_history, permissions, permission_logs, connectors, connector_settings.

Миграция `0004_productivity.sql` расширяет notes, tasks, snippets и добавляет таймеры, секундомеры и историю. Миграция `0010_integrations.sql` расширяет `connectors` (выданные разрешения, последняя проверка) и добавляет `connector_logs`.

Новая миграция — следующий файл `src-tauri/src/db/migrations/0010_*.sql`. Уже применённые миграции не редактируйте: sqlx проверяет их контрольные суммы.

## Frontend (`src`)
| Путь | Назначение |
|---|---|

| `lib/theme.ts`, `lib/settings-context.tsx` | тёмная / светлая / системная тема и настройки приложения |
| `components/` | `TitleBar`, `Sidebar` (на узком окне — только иконки), `Toasts`, UI-примитивы, тела виджетов |
| `pages/` | Обзор, Виджеты, Макеты, Автоматизации, Модули, Настройки, Разрешения, Интеграции, О программе, Документация (`docs/*.md` вшиты в сборку), Дизайн-система |

| `components/ui.tsx`, `Modal.tsx` | компоненты дизайн-системы — см. [design-system.md](design-system.md) |

Адаптивность: меню сворачивается до иконок при ширине меньше `lg`; сетки страниц перестраиваются от 1 до 4 колонок.

Безопасность: CSP разрешает только локальные ресурсы и IPC. Фронтенду выданы лишь права на управление окном (перетаскивание, свернуть, развернуть, закрыть) и `opener` (показать файл в папке). Хоткеи, автозапуск и состояние окна доступны только из Rust.

## Тесты
`cd src-tauri && cargo test --lib` — 123 теста, в основном на in-memory SQLite: миграции, настройки, разрешения, модули, макеты и виджеты, автоматизации (валидация, CRUD, расписание), манифесты и Offline Mode интеграций, ошибки.

## Производительность
- **Фронтенд.** Страницы, кроме Обзора и Центра управления, грузятся по требованию (`React.lazy`); основной бандл ~450 КБ.
- **Виджеты.** Данные кэшируются (до 200 записей). Опрос идёт не чаще раза в 2 с и останавливается при скрытом окне. События прореживаются: не больше одного обновления виджета в секунду. Тикеры часов не перерисовывают скрытое окно.
- **Backend.** Фоновые задачи модулей — задачи tokio. Они запускаются вместе с модулем и останавливаются вместе с ним.
- **Лимиты.** Вывод процессов — до 1 МБ, история буфера — `max_items` и `retention_days`, журналы модулей, интеграций и автоматизаций — ограничены настройками, diff — обрезается.
- **Завершение.** При выходе фоновые задачи останавливаются, WAL сбрасывается (настройка модуля «База данных»), пул SQLite закрывается с таймаутом 3 с, метка сеанса снимается.

## Надёжность
- **Сбой.** `session.lock` и текст паники — уведомление о сбое при следующем запуске.
- **Ошибки интерфейса.** `ErrorBoundary` изолирует ошибку страницы.
- **Резервная копия:** `VACUUM INTO`. Восстановление подменяет файл базы до её открытия; старая база сохраняется рядом.
- **Обновление.** Перед установкой база копируется в `backups/pre-update-<версия>.sqlite`.

## Сборка и релиз
- `build.rs` встраивает манифест Windows (`windows-app-manifest.xml`: Common Controls v6, DPI, длинные пути) через компоновщик, поэтому тестовые бинарники тоже запускаются.
- Сборка:
  - NSIS — `npm run release:nsis`;
  - portable — `npm run release:portable`.
- Подпись кода и автообновления — [release.md](release.md).
