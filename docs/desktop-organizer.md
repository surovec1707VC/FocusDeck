# Desktop Organizer — API

Модуль `desktop_organizer` (категория «Файлы», по умолчанию выключен) раскладывает файлы рабочего стола по папкам.

Код: `src-tauri/src/organizer/` — `rules.rs` (категории и правила), `mover.rs` (план, перемещение, журнал, откат), `mod.rs` (режимы и команды). Страница: `src/pages/Organizer.tsx`, в меню — «Рабочий стол».

## Гарантии

- **Ничего не удаляется.** Файлы только перемещаются. Существующие файлы не перезаписываются: при совпадении имени добавляется « (2)», « (3)»…
- При перемещении на другой диск файл сначала копируется. Оригинал убирается только после проверки размера копии; если размер не совпал, оригинал остаётся на месте.
- **Не трогаются:**
  - папки;
  - ярлыки (`.lnk`, `.url`);
  - скрытые и системные файлы (например, `desktop.ini`);
  - файлы, изменённые за последние `min_age_minutes` минут (недокачанные загрузки);
  - файлы под масками исключений.
- Каждое перемещение записывается в журнал и может быть отменено.
- Рабочий стол определяется через Windows, поэтому учитывается перенос в OneDrive.

**Полное отключение.** Если выключить модуль в Центре управления:
- останавливается фоновая задача (расписание, проверка лимита, запуск при входе);
- команды возвращают `module_disabled`;
- страница скрывается.

Журнал и правила сохраняются.

## Правила

Правила проверяются сверху вниз; срабатывает первое включённое правило, у которого выполнены **все** заданные условия. Новые правила пользователя добавляются в начало списка: конкретные правила должны срабатывать раньше общих стандартных.

```ts
interface OrganizerRuleInput {
  name: string;
  enabled: boolean;
  match: {
    categories?: FileCategory[];   // по типу файла
    extensions?: string[];         // по расширению ("pdf", без точки)
    name_pattern?: string;         // по названию: маска * и ?, без учёта регистра
    older_than_days?: number;      // по дате изменения
    newer_than_days?: number;
    min_size_kb?: number;
    max_size_kb?: number;
  };
  target: string;                  // целевая папка (шаблон)
}
```

Шаблон целевой папки:
- `{root}` — корневая папка из настроек;
- `{category}` — название категории;
- `{ext}` — расширение;
- `{year}`, `{month}`, `{day}` — по дате изменения файла;
- `%ПЕРЕМЕННЫЕ%` окружения.

Относительный путь считается внутри `{root}`; `..` и символы `* ? " < > |` запрещены. Правило без единого условия сохранить нельзя.

Стандартные правила — по одному на категорию: `{root}\Скриншоты\{year}-{month}`, `{root}\Изображения`, `{root}\Документы`, `{root}\Архивы`, `{root}\Установщики`, `{root}\Видео`, `{root}\Музыка`, `{root}\Код`, `{root}\Прочее`. Их можно отключать, менять, двигать и восстановить кнопкой «Стандартные правила».

### Примеры правил

```json
[

    "match": { "name_pattern": "Счёт*", "extensions": ["pdf"] },

  { "name": "Старые загрузки", "enabled": true,
    "match": { "categories": ["installers", "archives"], "older_than_days": 14 },

    "match": { "categories": ["images"], "min_size_kb": 500 },
    "target": "%USERPROFILE%\\Pictures\\{year}\\{month}" },

    "match": { "categories": ["video"], "min_size_kb": 1048576 },

```

## Режимы работы

| Режим | Как запускается |
|---|---|
| Ручной | вкладка «Упорядочить»: предпросмотр → выбор файлов → «Переместить выбранные» |
| По кнопке | «Упорядочить сразу» (с подтверждением): всё, что подходит под правила, без выбора файлов; отмена — в журнале |
| По расписанию | `schedule_enabled`, `schedule_time` (ЧЧ:ММ), `schedule_weekdays_only` |
| При входе в систему | `run_on_login`: FocusDeck запущен в течение 15 минут после загрузки Windows |
| По лимиту | `limit_enabled`, `file_limit`: срабатывает один раз, когда файлов на столе становится больше лимита; снова — после того как их станет не больше лимита |

Автоматические режимы работают так, как задано в `auto_mode`:
- `preview` (по умолчанию) — ничего не перемещают, а готовят предпросмотр и присылают уведомление. Пользователь проверяет список на странице и подтверждает.
- `move` — перемещают сразу. Отмена доступна в журнале.

## Предпросмотр

`organizer_preview()` возвращает:
- `items` — что, куда и по какому правилу будет перемещено;
- `targets` — список папок назначения с числом файлов;
- `skipped` — пропущенные файлы с причиной;
- `desktop_files` — сколько файлов на рабочем столе.

В интерфейсе можно:
- снять отметку с файла («не перемещать сейчас»);
- исключить файл навсегда: команда `organizer_exclude(name)` добавляет имя в `exclude_patterns`;
- нажать «Отмена» — снять все отметки.

`organizer_apply(items)` перемещает только переданные файлы. Перед перемещением каждый файл проверяется ещё раз: он должен по-прежнему лежать на рабочем столе.

## Журнал и Undo

| Команда | Что делает |
|---|---|
| `organizer_operations(limit?)` | операции: источник, статус (`done`, `partial`, `undone`, `partially_undone`), счётчики |
| `organizer_moves(operation_id)` | каждый файл: откуда, куда, правило, статус (`moved`, `failed`, `undone`, `undo_failed`), ошибка |
| `organizer_undo_last()` | откат последней операции, в которой ещё есть перемещённые файлы |
| `organizer_undo_operation(id)` | откат выбранной операции |
| `organizer_restore(move_ids)` | восстановление выбранных файлов из любой операции |

При откате файл возвращается на прежнее место:
- если имя уже занято — сохраняется как «имя (восстановлено).ext» (путь пишется в `restored_path`);
- если файла нет там, куда его переместили (его удалили или переместили вручную) — ставится статус `undo_failed` с объяснением, больше ничего не трогается.

Созданные папки назначения при откате не удаляются.

## Прочие команды

| Команда | Что делает |
|---|---|
| `organizer_rules()` | список правил |
| `organizer_save_rule(id?, input)` | создать или изменить правило |
| `organizer_delete_rule(id)` | удалить правило |
| `organizer_reorder_rules(ids)` | новый порядок правил |
| `organizer_reset_rules()` | вернуть стандартные правила |
| `organizer_run_now()` | «Упорядочить сразу» |
| `organizer_pending()` / `organizer_dismiss_pending()` | автоматический предпросмотр, ожидающий проверки |
| `organizer_paths()` | пути рабочего стола и корневой папки |
| `organizer_open_folder(path)` | открыть папку в Проводнике |

Событие `focusdeck://organizer-changed` — после перемещения, отката или автоматического предпросмотра.

## Схема БД

Миграция `0007_desktop_organizer.sql`:
- `organizer_rules(id, name, enabled, position, match_json, target, builtin)`;
- `organizer_operations(id, source, status, moved_count, failed_count, summary, created_at, undone_at)`;
- `organizer_moves(id, operation_id, original_path, new_path, rule_name, size, status, error, moved_at, undone_at, restored_path)`.

## Тесты

Тесты проверяют:
- определение категорий, условия правил, шаблоны папок, проверку правил, порядок правил;
- свободные имена файлов;
- полный сценарий на временной папке: предпросмотр, исключения, перемещение без перезаписи, частичный и полный откат, восстановление под другим именем, пропавший файл.
