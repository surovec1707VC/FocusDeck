# Список изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.1.4] — 2026-10-29

### Добавлено
- **Темы «Бенто» и «Стекло».** «Бенто» — тёмная: почти чёрный фон, фиолетовый акцент, крупные скругления. «Стекло» — светлая: пастельный градиент, полупрозрачные матовые карточки и боковая панель. Выбираются в Настройках → Тема и при первом запуске.

### Исправлено
- Виджет «Музыка» иногда показывал «медиа-элементы Windows недоступны… (0x80010002)». Обращения к медиа-службе Windows теперь идут через отдельный поток, отклонённые вызовы повторяются, а при кратковременном сбое виджет показывает последний известный трек.

## [0.1.3] — 2026-10-29

### Добавлено
- **Оформление виджетов.** В настройках любого виджета — «Своё оформление»: форма (скруглённая, квадратная, мягкая, капсула, срезанные углы), цвет (палитра или свой), текстура (стекло, градиент, точки, сетка, штриховка, шум) и непрозрачность, с предпросмотром.
- **Мини-плеер.** Виджет «Музыка» на рабочем столе сворачивается в маленькую капсулу поверх окон, когда вы переключаетесь в другое окно, и разворачивается по клику. Отключается в настройках модуля «Музыка».

## [0.1.2] — 2026-10-27

### Добавлено
- **Виджеты на рабочем столе.** Любой виджет можно открепить кнопкой «На рабочий стол»: он открывается в отдельном окне без рамки и фона, его можно двигать и менять размер, положение запоминается между запусками. Вернуть — кнопкой в окне виджета или в меню «Скрытые» на обзоре.
- **Виджет «Музыка».** Что сейчас играет в Windows (Spotify, браузер, Яндекс Музыка и др.): трек, исполнитель, программа, обложка, кнопки управления и анимированный эквалайзер (учитывает «уменьшение движения»). Нужно разрешение «Медиа: что сейчас играет».

## [0.1.1] — 2026-10-23

### Добавлено
- **Автообновление через GitHub Releases.** При запуске программа проверяет новую версию и показывает окно «Доступно обновление».

## [0.1.0] — 2026-10-23

Первый выпуск.

### Добавлено
- **Оболочка.** Окно без системной рамки, трей, автозапуск, глобальные горячие клавиши, тёмная и светлая темы.
- **Центр управления и реестр модулей.** 43 модуля; каждый, кроме критических, можно выключить. У модулей есть настройки, статус, журнал и разрешения.
- **Виджеты и макеты.** 14 виджетов, сетка с перетаскиванием и изменением размера, несколько макетов с горячими клавишами.
- **Продуктивность.** Заметки (Markdown), задачи, сниппеты, таймеры и секундомеры.
- **Clipboard Hub.** История буфера обмена, приватные окна, быстрые действия.
- **Automations.** 12 триггеров, 7 видов условий, 18 действий, шаблоны, тестовый запуск, журнал.
- **Desktop Organizer.** Правила, предпросмотр, перемещение без удаления, откат.
- **Windows Integration.** Окна, приложения, звук, яркость, питание, скриншоты. Есть Permissions Center, Safe Mode и Action Log.
- **Developer Tools.** Git, Project Launcher, терминалы, API Tester, Regex Tester, JSON/YAML.
- **Интеграции.** 13 коннекторов-манифестов, секреты в Windows Credential Manager, Offline Mode.
- **Интерфейс.** Быстрый поиск (Ctrl+K), знакомство при первом запуске, встроенная документация, дизайн-система.
- **Надёжность.** Уведомление о сбое прошлого сеанса, резервная копия базы и её восстановление, экспорт и импорт данных.
- **Обновления.** Проверка, список изменений, установка подписанных пакетов, откат данных.

### Безопасность
- Защита путей от выхода за пределы папки.
- Защищённые системные папки.
- Закрытие программ без командной оболочки.
- Разрешения по умолчанию выключены.
